# Onboarding — anoda

One document that answers "what is this, where are we, and where do I look" for a new developer, a new agent
session, or the owner coming back after a break.

## What anoda is

`anoda` is a personal microservices monorepo: Go backends and Next.js frontends, run locally with Docker Compose
today and designed to move to Kubernetes without rewrites, exposed to the owner over Tailscale. Because most code
here is written by AI agents across disconnected sessions, the project leads with a written **engineering
contract** (`docs/contracts/`) instead of relying on shared memory or convention-by-osmosis.

**What it is not, yet:** there is no running product. The services in `services/` are named and described in
outline, but none has code, a database schema, or a UI. The work done so far is entirely the *foundation* —
the rules and tooling every future service will be built on — not a feature.

### What "foundation complete" actually means

Everything below was built and independently verified working, not just written:

- 13 binding contracts (`docs/contracts/00`–`12`) covering repo conventions, the Go stack, the Next.js stack,
  mandatory testing, security, API design, SOLID/design patterns, observability, containers/deploy, LLM
  integration, agent workflow, and design/UI/UX.
- 10 ADRs recording *why* each stack choice was made (`docs/adr/`).
- Enforcement tooling that makes the contracts real: shared `golangci-lint`, ESLint/Prettier/Vitest/TypeScript
  configs, reference Dockerfiles, per-stack Taskfiles, a design-token system with an automated WCAG contrast
  checker, and a per-package Go coverage gate — all under `tooling/`.
- A CI workflow (`.github/workflows/ci.yml`) that mirrors `task check` exactly, path-filtered so it only runs
  jobs relevant to what changed.
- Git hooks (lefthook) enforcing formatting, commit message style, and secret scanning before anything is
  committed or pushed.
- Bootstrap scripts (`scripts/bootstrap.ps1` / `.sh`) that install the whole toolchain on a fresh machine.

Verified by hand: the coverage gate correctly fails under-covered packages and passes exempted ones; the design
contrast checker caught and a fix resolved one real WCAG failure; gitleaks blocks a staged fake credential;
commitlint rejects a non-conventional commit message and accepts a valid one; the Tailwind preset type-checks;
`docker compose config`, `markdownlint`, and `actionlint` all pass.

## Architecture at a glance

| Layer | Choice | Why (ADR) |
|---|---|---|
| Go backend | stdlib `net/http` (Go 1.22+ routing) + chi, `pgx/v5`, `sqlc`, `golang-migrate`, hexagonal architecture | [0002](docs/adr/0002-go-stdlib-chi-sqlc-postgres.md) |
| Frontend | Next.js App Router, TypeScript strict, Server Components by default | [0003](docs/adr/0003-nextjs-app-router-typescript-strict.md) |
| Local hosting | Docker Compose now, images already Kubernetes-ready | [0004](docs/adr/0004-docker-compose-first-kubernetes-ready.md) |
| Task runner | Taskfile (`go-task`), cross-platform | [0005](docs/adr/0005-taskfile-as-task-runner.md) |
| Auth | Google Sign-In (OIDC), email allowlist, no passwords | [0006](docs/adr/0006-google-oidc-email-allowlist-auth.md) |
| API contract | OpenAPI 3.1 first, generated clients/servers, RFC 9457 errors | [0007](docs/adr/0007-openapi-first-rest-contracts.md) |
| Design system | Tailwind CSS + shadcn/ui, shared design tokens, WCAG 2.2 AA | [0008](docs/adr/0008-tailwind-shadcn-design-tokens.md) |
| Exposure | Tailscale (`tailscale serve`; `funnel` only with an ADR) | [09-containers-and-deploy.md](docs/contracts/09-containers-and-deploy.md) |

Services never share a database or call each other directly from a browser; everything crosses a boundary
through a versioned HTTP API described in that service's `api/openapi.yaml`.

## How to run it

See [`START.md`](START.md) for the copy-paste version. Short version: `bash scripts/bootstrap.sh` (or the
`.ps1` on Windows), then `task check` and `task up`.

## How to work in this repo

You are almost certainly an AI agent, or a human reading the agent's rules. Start at [`CLAUDE.md`](CLAUDE.md).
It links to the contract for whatever you're about to touch. The short version: unit tests are mandatory,
`task check` must pass, no secrets, no weakened gates without an ADR, and every new screen needs a spec in
`docs/design/screens/` before it's built.
